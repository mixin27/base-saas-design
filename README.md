# Nimbus - Base SaaS Design

A comprehensive, beautifully designed template for a modern SaaS application. This repository provides foundational layouts, components, and pages tailored for a SaaS application's administration and tenant views.

## Features

- **Responsive Design:** Mobile-first approach using standard HTML/CSS.
- **Admin Dashboard:** Layouts for managing users, plans, tickets, and emails.
- **Tenant Dashboard:** Templates for standard SaaS user workflows.
- **Design System:** Included basic design system principles.

## Structure

- `/admin`: Administrative views.
- `/tenant`: Tenant/user views.
- `/shared`: Reusable components and assets.
- `/landing`: Landing page templates.
- `/design-system`: Core CSS and design tokens.

## Getting Started

To view the templates, simply open the `.html` files in any modern web browser. No complex build tools or servers are required!
